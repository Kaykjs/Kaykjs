## 📌 Projeto em destaque

### 🏠 Site para imobiliária — [cardoso-machado.vercel.app](https://cardoso-machado.vercel.app)

Site institucional com catálogo de imóveis e painel administrativo. **Desenvolvido e vendido para um cliente real.**

- 🔎 Catálogo com filtros (tipo, bairro, preço, quartos, área) e busca por título ou código
- 🖼️ Página de cada imóvel com galeria de fotos, preço, IPTU e botão que abre o WhatsApp da empresa já com o código do imóvel
- 🔐 Painel admin com login: os donos cadastram, editam e removem imóveis, enviam fotos e escolhem os destaques sem depender de programador
- 📝 Páginas de início, sobre, contato e formulário de avaliação de imóvel

**Stack:** Next.js 15 (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui · Framer Motion · PostgreSQL (Neon) · Prisma · Auth.js · Zod · Vercel Blob · Vercel
